# Vigilancia Judicial y Administrativa - Colombia

Plataforma integral para seguimiento, análisis y vigilancia de procesos judicales y administrativos en Colombia.

## 🎯 Características principales

- ✅ Seguimiento de expedientes judicales
- ✅ Alertas de fechas importantes y audiencias
- ✅ Gestión de procesos administrativos
- ✅ Análisis de sentencias y resoluciones
- ✅ Reportes y estadísticas
- ✅ Gestión de documentos
- ✅ Notificaciones automáticas

## 🏗️ Stack Tecnológico

### Frontend
- React 18 + TypeScript
- Vite (bundler rápido)
- Tailwind CSS (estilos)
- React Router (navegación)
- Zustand (state management)

### Backend
- Node.js + Express
- PostgreSQL (base de datos)
- Prisma (ORM)
- JWT (autenticación)
- Socket.io (notificaciones en tiempo real)

## 📁 Estructura del Proyecto

```
vigilancia-judicial/
├── frontend/          # Aplicación React
├── backend/           # Servidor Node.js/Express
├── docs/              # Documentación
├── docker-compose.yml # Configuración Docker
└── package.json       # Dependencias raíz
```

## 🚀 Primeros Pasos

1. Instalar dependencias: `npm install`
2. Configurar variables de entorno
3. Iniciar desarrollo: `npm run dev`
